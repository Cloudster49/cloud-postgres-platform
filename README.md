# Cloud-Ready PostgreSQL Production Platform

A production-style PostgreSQL environment designed to demonstrate database administration, performance engineering, automation, backup and recovery, disaster recovery, monitoring, and eventually cloud deployment.

## Project Goals

- PostgreSQL database administration
- Relational database design
- SQL performance optimization
- Automated data generation
- Backup and recovery
- Disaster recovery testing
- Database monitoring
- Python and Bash automation
- Cloud deployment
- Infrastructure as Code
- CI/CD

## Technology Stack

- PostgreSQL
- Python
- Bash
- Docker
- Git/GitHub
- Azure
- Terraform
